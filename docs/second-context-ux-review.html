    60-minute focused UX review

    외부 전문가의 눈으로, 무엇부터 고칠지 정합니다.

    특정 제품 흐름이나 화면에 대해 판단과 개선 우선순위가 필요한 파운더·PM·제품팀을 위한 집중 리뷰입니다.

    • US$200USD 결제
    • 60분화상 리뷰
    • 한국어 · 영어진행 언어 선택
    • 2영업일서면 요약(초안 조건)

    리뷰 신청 문의UX 리뷰 결제하기 · US$200 (새 탭에서 열림)

    01

    포함 내용

    1. 01범위핵심 사용자 흐름 1개 또는 주요 화면 최대 5개
    2. 02사전 검토보내 주신 자료를 최대 30분 동안 미리 검토합니다
    3. 0360분 화상 리뷰한국어 또는 영어로 함께 화면을 보며 문제와 선택지를 이야기합니다
    4. 04서면 요약핵심 문제·권고·개선 우선순위·다음 행동 — 통화 후 2영업일 이내 전달(초안 조건)

    02

    진행 순서

    1. 1리뷰 신청 문의문의 폼에서 ‘60분 집중 UX 리뷰’와 진행 언어를 선택해 보내 주세요.결제‘UX 리뷰 결제하기’ 버튼에서 Stripe로 US$200를 결제합니다.
    2. 2일정·결제 안내가능한 일정과 결제 방법을 이메일로 안내드립니다. 결제 후 예약이 확정됩니다.일정 안내결제 후 남겨주신 이메일로 가능한 일정과 진행 언어를 확인합니다.
    3. 3자료 공유제품 URL, 검토할 화면이나 프로토타입, 대상 사용자와 현재 고민을 보내 주세요.
    4. 4사전 검토최대 30분 동안 자료를 미리 살펴봅니다.
    5. 560분 화상 리뷰함께 화면을 보며 문제와 우선순위를 이야기합니다.
    6. 6서면 요약통화 후 2영업일 이내에 요약을 보내드립니다(초안 조건).

    03

    준비할 자료

    • 제품 URL
    • 검토할 화면 또는 프로토타입
    • 대상 사용자
    • 검토할 흐름과 현재 고민
    • 상담 후 결정하고 싶은 사항

    실제 개인정보·결제정보·비밀번호는 보내지 마세요. 익명화한 화면, 예시 데이터, 안전한 데모 자료로 충분합니다.
    NDA가 필요하면 자료를 공유하기 전에 문의해 주세요.

    04

    포함하지 않는 것

    • 세션 녹화(기본 제공에 포함되지 않음)
    • 완성 디자인
    • 개발
    • 사용자 테스트
    • 무제한 후속 상담

    전환율 향상 등 특정 성과를 보장하지 않습니다. 더 깊은 진단이 필요하면 UX 진단 스프린트를, 구체적인 개선 설계까지 필요하면 복잡한 제품 흐름 개선 스프린트를 문의해 주세요.

    UX 진단 스프린트 보기

    05

    신청과 결제

    결제 안내

    온라인 결제 연결 준비 중입니다. 신청 후 진행 가능 일정과 결제 방법을 안내드립니다. 신청은 예약 확정이나 결제 완료를 의미하지 않습니다.

    아래 버튼을 누르면 Stripe 결제 페이지가 새 탭에서 열립니다. 결제 후 남겨주신 이메일로 일정과 자료 공유 방법을 안내드립니다.

    상담과 리뷰는 한국어 또는 영어로 진행합니다. 예약 화면의 언어와 관계없이 원하는 진행 언어를 선택할 수 있습니다.
