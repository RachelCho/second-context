    번역된 문장을 넘어, 한국어 사용자에게 자연스러운 제품으로.

    글로벌 테크 기업의 데스크톱 제품 콘텐츠를 한국 시장에 맞추며, 문구와 함께 이름·날짜·시간 표기, 타이포그래피와 간격까지 한국어 사용 맥락에 맞게 조정했습니다.

    Overview

    프로젝트 소개

    사용 맥락과 과제
    5K 디스플레이 데스크톱 제품 관련 콘텐츠를 한국 시장에 맞추는 프로젝트였습니다. 글로벌 브랜드의 표현과 한국어의 자연스러운 문구·레이아웃을 함께 유지해야 했습니다.
    Rachel의 역할
    UX 문구와 디자인 자산을 현지화하고, 팀 간 소통을 지원했습니다.
    공개 가능한 협업 범위
    2019년 6주 동안 영국의 글로벌 제작 에이전시, 고객사의 한국 팀·미국 팀과 협업했습니다.
    프로젝트 성격
    이전 경력 프로젝트 · 6주 · 2019

    Rachel Cho의 이전 경력에서 수행한 프로젝트입니다. 공개 가능한 범위의 경험을 소개하며, 화면과 데이터는 설명을 위해 새롭게 구성한 예시입니다.

    Problem

    영어 원문을 그대로 옮기면 이름 순서, 날짜·시간 표기, 문장 길이와 줄바꿈이 한국어 사용자에게 어색하게 읽혔습니다.

    Design Response

    글로벌 브랜드의 표현은 지키면서, 한국어 사용자가 익숙한 표기 순서와 읽는 흐름에 맞춰 문구와 화면 구성을 조정했습니다.

    Key decisions

    핵심 설계 판단

    01

    문구만이 아니라, 이름·날짜·시간 표기까지.

    글로벌 브랜드의 표현과 한국어의 자연스러움을 함께 지켜야 했기 때문에, 문구만 옮기지 않고 이름·날짜·시간 표기 방식까지 한국어 관례에 맞췄습니다.

    사용자에게 생긴 차이 같은 정보를 익숙한 순서로 읽어, 다시 해석할 필요가 없습니다.

    설계 설명을 위한 재구성 · 실제 프로젝트 화면이 아닌 예시 문구

    Original

    Hi, Jimin Kim

    A display that brings every detail to life.

    Delivery: Tue, Jun 4, 2019

    Pickup after 3:30 PM

    한국어

    김지민 님, 안녕하세요

    모든 디테일을 생생하게 담아내는 디스플레이.

    배송: 2019년 6월 4일 (화)

    픽업: 오후 3:30 이후

    1. 원문 화면 영어 원문의 이름·날짜·시간 표기와 문장 길이를 기준으로 삼습니다.

    2. 한국어 화면 같은 정보를 한국어 사용자가 익숙한 순서와 표기로 옮깁니다.

    3. 변경 지점

    1. 이름: 성-이름 순서와 ‘님’ 호칭
    2. 날짜: 연-월-일 순서, 요일은 괄호로
    3. 시간: 오전·오후를 숫자 앞에
    4. 문구·줄바꿈: 단어 단위 줄바꿈과 한글에 맞춘 글자 간격
    02

    한국어 문장에 맞춘 타이포그래피와 간격.

    같은 이유로 타이포그래피와 간격을 한국어 문장에 맞춰 조정했습니다. 문구 길이가 달라져도 버튼과 줄바꿈이 자연스럽게 읽히도록 레이아웃을 맞췄습니다.

    사용자에게 생긴 차이 번역된 화면이 아니라, 처음부터 한국어로 만든 화면처럼 읽힙니다.

    03

    세 팀의 관점이 어긋나지 않도록.

    영국·한국·미국 팀의 관점이 어긋나지 않도록 팀 간 소통을 지원했습니다. 브랜드 표현과 한국어 관례가 부딪히는 지점을 함께 확인하며 산출물을 정리했습니다.

    사용자에게 생긴 차이 한국어 사용자에게 닿는 문구와 화면이 한 방향으로 정리됩니다.

    Results

    결과와 배운 점

    확인된 산출물

    • 한국 시장에 맞춘 UX 문구와 디자인 자산
    • 이름·날짜·시간 표기
    • 한국어 타이포그래피와 간격을 반영한 현지화 레이아웃

    프로젝트 기간

    • 프로젝트 기간6주2019년, 제작 에이전시와 고객사의 한국·미국 팀이 함께한 현지화 기간

    배운 점

    현지화는 번역의 정확도만이 아니라, 사용자가 익숙한 표기와 읽는 흐름을 지키는 디자인 작업이라는 점을 배웠습니다.

    이 프로젝트는 확인된 성과 수치가 없어 산출물과 배운 점으로 정리했습니다. 비교 화면의 문구는 실제 프로젝트 화면이 아닌 예시입니다.
