    • Previous-role project

    Beyond translated sentences, a product that feels natural in Korean.

    Adapting a global tech company’s desktop product content for Korea, the work went beyond copy to name, date, and time formats, typography, and spacing suited to how Korean is read and used.

    Overview

    About the project

    Context and challenge
    A project adapting content for a 5K-display desktop product to the Korean market, keeping the global brand’s expression while making Korean copy and layout read naturally.
    Rachel’s role
    Localized UX copy and design assets and supported communication between teams.
    Collaboration (public scope)
    Worked for 6 weeks in 2019 with a global production agency in the U.K. and the client’s Korea and U.S. teams.
    Project type
    Previous-role project · 6 weeks · 2019

    A project Rachel Cho delivered in a previous role. It covers only what can be shared publicly; screens and data are new examples created for illustration.

    Problem

    Carrying the English original over as-is made name order, date and time formats, sentence length, and line breaks read awkwardly for Korean users.

    Design Response

    Keeping the global brand’s expression, copy and layout were adjusted to the formats and reading flow Korean users expect.

    Key decisions

    Key design decisions

    01

    Not just copy—name, date, and time formats too.

    Because both the global brand’s expression and natural Korean had to be preserved, name, date, and time formats were matched to Korean conventions, not just the copy.

    What changed for users The same information reads in a familiar order, with nothing to reinterpret.

    Recreated for illustration · Sample copy, not actual project screens

    1. Original screen The English original’s name, date, and time formats and sentence length are the starting point.

    2. Korean screen The same information is carried over in the order and formats Korean users expect.

    3. What changed

    1. Names: family name first, with the honorific 님
    2. Dates: year-month-day order, with the weekday in parentheses
    3. Times: 오전/오후 (a.m./p.m.) before the numbers
    4. Copy and line breaks: breaking lines at word boundaries, with spacing suited to Korean text
    02

    Typography and spacing fitted to Korean text.

    For the same reason, typography and spacing were adjusted for Korean text, and layouts were tuned so buttons and line breaks still read naturally when copy length changes.

    What changed for users Screens read as if they were made in Korean, not translated.

    03

    Keeping three teams aligned.

    Supported communication so the U.K., Korea, and U.S. teams stayed aligned, working through the points where brand expression and Korean conventions met before finalizing deliverables.

    What changed for users Copy and screens that reach Korean users land in one consistent direction.

    Results and lessons
