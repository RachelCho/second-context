    무료 30분 상담

    무료 · 30분 화상

    포함

    • 제품·목표 시장·현재 고민에 대한 30분 대화

    결과물

    별도 결과물은 없으며, 대화 후 맞는 진행 방식을 안내합니다.

    자세한 조건
    이런 팀에 맞습니다

    상담과 리뷰는 한국어 또는 영어로 진행합니다. 예약 화면의 언어와 관계없이 원하는 진행 언어를 선택할 수 있습니다.

    02

    60분 집중 UX 리뷰

    US$200 · 60분 화상 리뷰 + 서면 요약

    이 단계에서 얻는 것특정 문제에 대한 전문가 판단

    포함

    • 핵심 사용자 흐름 1개 또는 주요 화면 최대 5개
    • 사전 자료 검토 최대 30분
    • 한국어 또는 영어로 진행하는 60분 화상 리뷰

    결과물

    핵심 문제, 권고 사항, 개선 우선순위와 다음 행동을 정리한 서면 요약.

    통화 후 2영업일 이내 전달합니다. (조건 초안)

    자세한 조건
    이런 팀에 맞습니다
    특정 제품 흐름이나 화면에 대해 외부 전문가의 판단과 개선 우선순위가 필요한 파운더·PM·제품팀
    별도 범위
    세션 녹화, 완성 디자인, 개발, 사용자 테스트, 무제한 후속 상담

    전환율 향상 등 특정 성과를 보장하지 않습니다.

    결제 안내

    온라인 결제 연결 준비 중입니다. 신청 후 진행 가능 일정과 결제 방법을 안내드립니다. 신청은 예약 확정이나 결제 완료를 의미하지 않습니다.

    아래 버튼을 누르면 Stripe 결제 페이지가 새 탭에서 열립니다. 결제 후 남겨주신 이메일로 일정과 자료 공유 방법을 안내드립니다.

    UX 진단 스프린트

    US$1,500부터 · 심층 UX 진단 · 개선 설계는 포함하지 않습니다

    이 단계에서 얻는 것무엇을 먼저 고쳐야 하는지에 대한 진단·우선순위

    포함

    • 제품 1개, 플랫폼 1개
    • 핵심 사용자 흐름 1~2개
    • 주요 화면 최대 10개
    • 결과 설명 통화 60분

    결과물

    • 화면 주석과 문제 설명
    • 사용자 영향과 개선 우선순위
    • 구체적인 권고
    자세한 조건
    이런 팀에 맞습니다
    핵심 흐름과 주요 화면의 문제를 깊이 살펴보고, 무엇부터 고칠지 근거를 갖고 정하고 싶은 팀
    진행 기간
    자료와 범위 확정 후 약 1~2주
    가격이 달라지는 요인
    • 추가 화면·흐름·플랫폼
    • 사용자 역할과 예외 상황의 복잡성
    • 경쟁사 분석
    • 와이어프레임·프로토타입
    • 추가 회의·수정·구현 지원

    기본 범위를 넘는 작업은 시작 전에 별도 견적으로 합의합니다. 결제는 범위 확정 후 안내드립니다.

    결제 안내

    결제는 범위 확정 후 안내드립니다.

    FAQ

    자주 묻는 질문

    가격은 어떤 통화인가요?

    모든 가격은 미국 달러(USD) 기준이며, 결제도 USD로 진행합니다. 한국어·영어 페이지의 가격은 같습니다.

    결제는 어떻게 하나요?

    온라인 결제 연결 준비 중입니다. 신청 후 진행 가능 일정과 결제 방법을 안내드립니다. 신청은 예약 확정이나 결제 완료를 의미하지 않습니다.

    60분 집중 UX 리뷰는 Stripe 결제 링크로 미리 결제합니다. 결제 후 일정과 자료 공유 방법을 이메일로 안내드립니다.

    UX 진단 스프린트는 범위 확정 후 결제 방법을 안내드립니다.UX 진단 스프린트는 범위와 견적이 확정된 뒤 Stripe 결제 링크로 안내받은 금액을 결제합니다. 복잡한 제품 흐름 개선 스프린트는 범위 확정 후 결제 방법을 안내드립니다.복잡한 제품 흐름 개선 스프린트는 범위와 견적이 확정된 뒤 Stripe 결제 링크로 안내받은 금액을 결제합니다.

    한국에서도 결제할 수 있나요?

    네. 60분 UX 리뷰는 Stripe에서 해외 온라인 결제가 가능한 Visa 또는 Mastercard로 결제하실 수 있습니다. 결제 화면에 USD가 표시되면 카드사 환율과 해외 결제 수수료가 적용될 수 있습니다. 원화 결제를 원하시거나 카드 결제가 어려우시면 결제 전에 문의해 주세요. 스프린트는 작업 범위와 최종 금액을 확정한 뒤 결제 안내를 보내드립니다.

    상담은 어떤 언어로 진행하나요?

    상담과 리뷰는 한국어 또는 영어로 진행합니다. 예약 화면의 언어와 관계없이 원하는 진행 언어를 선택할 수 있습니다.

    리뷰 세션을 녹화해 주나요?

    세션 녹화는 기본 제공에 포함되지 않습니다.

    NDA를 체결할 수 있나요?

    필요한 경우 자료를 공유하기 전에 문의해 주세요.

    특정 성과를 보장하나요?

    전환율 향상 등 특정 성과는 보장하지 않습니다. 근거 있는 판단과 우선순위를 드립니다.

    취소·변경·환불 기준은 어떻게 되나요?

    유료 예약을 열기 전에 확정해 예약·취소·자료 처리 안내에 게시합니다. 그 전까지는 신청 후 개별 안내드립니다.
